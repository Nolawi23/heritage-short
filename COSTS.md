# Costs

Everything runs on free tiers, so the **actual cost is $0**. Every model call is logged in
[`runs.jsonl`](runs.jsonl) with `latency_ms`, `gpu_seconds`, `est_cost_usd` (what we paid: 0 on free tiers) and
`list_price_usd` (what the same call would cost at list price, from [`config/prices.json`](config/prices.json)).
`make costs` rebuilds the table below from the log.

## Measured limits

Free-tier limits measured on 2026-11-25. Gemini daily quotas reset at **midnight Pacific** (08:00 UTC = 11:00 EAT),
and **failed requests count** (503 retries used up a day's quota once, see FAILURES.md #6).

| Model / service | Requests per day | Requests per minute | Source |
|---|---|---|---|
| `gemini-3.8-flash-tts` (narration) | **10** | **3** | AI Studio rate-limit page |
| `gemini-3.8-flash` (text) | 20 | — | AI Studio; 429 text `generate_content_free_tier_requests, limit: 20` |
| `gemini-3.6-flash` (text, pinned for `script`) | 20 | 5 | AI Studio rate-limit page |
| Workers AI (FLUX.2 klein 4B) | 10,000 Neurons (~45 keyframes at 1792x1008) | — | Cloudflare pricing page |
| Kaggle GPU (T4) | 21,600 s **per week** (6 h), resets Saturday 00:00 UTC | — | `KaggleApi.quota_view()` in `make smoke` |

How the pipeline stays inside them (`config/models.json`):
- Minimum interval between calls: TTS ≥ 21 s, text ≥ 13 s. A failed TTS call is never retried within the same
  minute (`min_retry_s`), and TTS gets at most 2 attempts.
- Narration sends all uncached lines in **one** multi-speaker request (batch mode, ARCHITECTURE.md) instead of
  one request per line: a full 12-line narration costs 1 request instead of 12.
- `make budget` prints today's used/left requests per Gemini model, counted from `runs.jsonl`. The narration stage
  prints the TTS budget before every request and refuses locally when it is 0 (`status: quota_exhausted`, nothing sent).

## What one film costs (expected)

| Stage | Provider | Calls per film | Free-tier budget it uses | List-price basis |
|---|---|---|---|---|
| narration | Gemini 3.8 Flash TTS | 1 batch request (+1 per later edited line) | 1 of 10 requests/day; stops cleanly on quota and resumes from cache | per 1M text-in / audio-out tokens |
| keyframes | Workers AI FLUX.2 klein 4B | 4 reference candidates per character + 1 per shot | ~208 Neurons per 1792x1008 image (8 tiles x 26.05) of 10,000/day | $0.000287 per output tile, $0.000059 per input (reference) tile |
| shots | Kaggle T4 (Wan 2.2 TI2V-5B) | one kernel run for all changed wan shots | weekly Kaggle GPU hours: measured by `make shots-test` before the batch | T4 GPU-hour equivalent ($0.35/h, Google Cloud list price) |
| music | Kaggle T4 (ACE-Step 1.5 XL turbo) | one kernel run, 3 candidates per cue | a few GPU minutes | same as above |
| assemble, radio | local ffmpeg | n/a | none | 0 |

Reruns cost nothing: unchanged items are cache hits (`cache_hit: true` lines in `runs.jsonl`).
Prices were checked on 2026-11-25 and are flagged `verified: false` in `config/prices.json` where the source was not
read verbatim (Gemini TTS, FLUX.1 schnell fallback, T4 equivalent).
